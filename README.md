# -
一个挂机下载完成后触发关机的工具，识别百分比进度，详细见readme。


触发方式有两种：
1.当识别到进度达到100％
2.当进度≥20％，且识别不到进度的时候

触发关机的时候，延时30s后关机，可以用“shutdown /a”来取消关机

其中:
“1”方式适合于下载文件较大，或者速度较慢时候，此时百分比增长速度慢

“2”方式适合于下载文件较小，或者速度较快时候，此时百分比增长速度快

原理：
利用OCR识别进度，当识别到进度达到100％或者当进度≥20％，且识别不到进度的时候,触发关机命令。

特色：
1.可以自由设置OCR识别延时（1s-20s闭区间）
2.可以自由圈画OCR识别位点
3.内存占用小，visual studio测试的时候，内存占用不到100MB（圈画小范围）
